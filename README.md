# projek_pweb
### Projek ini adalah website portofolio pribadi yang aku bikin buat nampilin profil, minat, sama hasil karyaku. Di website ini, aku ngenalin diri sebagai mahasiswa Informatika Universitas Jember yang fokus di bidang design grafis, web development, sama fotografi. Tujuannya simpel, biar siapa pun yang buka website ku ini bisa langsung tau latar belakangku, ngeliat galeri karya yang udah aku bikin, dan gampang kalau mau nanya-nanya atau nyari kontakku.
1. Fitur Mode Terang & Gelap : Ada tombol di navbar yang memanfaatkan JavaScript yang ada DOM nya buat ngubah skema warna seluruh website dari tema gelap ke terang.
2. Adanya Layout Responsif: Tampilan website otomatis nyesuain ukuran layar, jadi tetep rapi waktu dibuka lewat laptop maupun HP.
3. Animasi Scroll Yang Menggunakan jQuery: buat ngasih efek elemen yang pelan-pelan muncul berurutan pas halamannya digeser ke bawah.
4. Fitur Kontak: Bagian kontak dilengkapi ikon dari FontAwesome yang langsung terhubung ke email, GitHub, Instagram, dan Pinterest milik saye.
